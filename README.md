# tutorial-mod

Historical Minecraft 1.15 Forge tutorial project containing experimental item and block code.

This project is unmaintained, and current build compatibility has not been verified. The inherited Forge MDK instructions remain in [README.txt](README.txt); they are historical instructions, not a validated setup guide.

Project code is under [src/main/java](src/main/java); Gradle configuration and resources remain unchanged. Existing [LICENSE.txt](LICENSE.txt) and [CREDITS.txt](CREDITS.txt) are retained. No new authorship or license claim is made over inherited material.
